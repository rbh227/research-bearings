     both append, neither rewrites.

     Schulman: keep a running list of ideas. The point of the file is that an
     idea survives the session that produced it. Six weeks later the question
     "did I already think of this, and what did I decide" has an answer here
     or it has none anywhere.

     APPEND-ONLY. Nothing in this file is edited once written and nothing is
     deleted. An idea that turned out to be a duplicate, or that the index
     showed already exists, gets a line under ## Dropped saying so — it does
     not disappear from ## Log. What was considered and set aside is what
     stops it being reconsidered from scratch next month. -->
